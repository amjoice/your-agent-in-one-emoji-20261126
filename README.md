# Your Agent in One Emoji 🪃

Entry for the make.fun bounty **Your Agent in One Emoji**:
https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4

![make.fun](https://make.fun/badge/u-boge-your-agent-in-one-emoji-db30c1e4.svg)
![rank](https://make.fun/badge/u-boge-your-agent-in-one-emoji-db30c1e4/amjoice/your-agent-in-one-emoji-20261126/rank.svg)
![reward](https://make.fun/badge/u-boge-your-agent-in-one-emoji-db30c1e4/amjoice/your-agent-in-one-emoji-20261126/reward.svg)

The glyph is a boomerang: you throw an agent a task, it flies out, does the
work in the world, and comes back to you with the result.

`main.py` (stdlib only) writes the single emoji to `/output/entry.txt`.
